# Professional Portfolio - Editing Guide

This guide explains how to update the content, add new projects, and deploy your portfolio.

## 📂 Project Structure

-   `index.html`: Main file containing all text, links, and structure. **Edit this to change content.**
-   `src/styles/`: Contains all CSS files for styling.
    -   `variables.css`: Change colors and fonts here.
    -   `sections.css`: Specific styles for each section (Hero, About, Projects, etc.).
-   `main.js`: Handles interactions and animations.
-   `public/`: Place images (like resume PDF or project screenshots) here.

## ✏️ How to Edit Content

### 1. Update Personal Details
-   Open `index.html`.
-   Search for `Kaparthy Sathwik` to change your name.
-   Search for "Computer Science & Engineering Student" to change your title.

### 2. Add New Projects
-   Open `index.html`.
-   Find the `<section id="projects">` block.
-   Copy an existing `<article class="project-card">...</article>` block.
-   Paste it where you want the new project to appear.
-   Update the `<h3>` (Title), `<p>` (Description), and `tags`.
-   **Crucial**: Update the `href` in `<a href="...">View Code</a>` to your new GitHub repository link.

### 3. Update Status ("Open to Work")
-   In `index.html`, find `<div class="status-badge">`.
-   To change status text, edit "Open to Work".
-   To hide it, add `style="display: none;"` to the `<div>`.

### 4. Update Resume Link
-   Currently, the "Request Resume" button links to `#contact`.
-   To link a PDF directly:
    1.  Place your PDF file (e.g., `resume.pdf`) in the `public/` folder.
    2.  In `index.html`, find the "Request Resume" button.
    3.  Change `href="#contact"` to `href="/resume.pdf"` and add `download` attribute if you want it to download immediately.

## 🚀 How to Run & Build

### Development (Live Preview)
Run this command to see changes in real-time:
```bash
npm run dev
```

### Build for Production
When you are ready to deploy (e.g., to GitHub Pages or Netlify), run:
```bash
npm run build
```
This creates a `dist/` folder with optimized files ready for upload.

## 🐙 Uploading to GitHub (For Storage & Updates)

**Important:** For GitHub, you must upload the **FULL PROJECT FOLDER**, not just `dist`.

### Steps:
1.  **Initialize Git** (if not done): `git init`
2.  **Add files**: `git add .`
3.  **Commit**: `git commit -m "Initial commit"`
4.  **Push**: Connect to your new GitHub repository and push.
    *   *Note: Using GitHub Desktop or VS Code's Source Control tab is easier!*

### What gets ignored?
The `.gitignore` file automatically ensures that `node_modules` (the heavy folder) and `dist` are **not** uploaded. This is correct and standard practice.

## 🌐 Deploying to Netlify (Fastest Way)

1.  **Locate the `dist` folder**: Inside your project folder, find the `dist` folder (created after running `npm run build`).
2.  **Login to Netlify**: Go to [app.netlify.com](https://app.netlify.com).
3.  **Drag & Drop**: Drag the **`dist`** folder (not the main project folder) directly onto the Netlify "Sites" page.
4.  **Done!**: Netlify will give you a live URL instantly.
